# Appanoose 2077

A NetNewsWire article theme based on the pre-bundled Appanoose theme and inspired by Cyberpunk 2077's computer/shard UI for in-game documents/text files - solid black page, ice-cyan text, and a bright cyan header bar, with [Rajdhani](https://fonts.google.com/specimen/Rajdhani) bundled in the theme.

### Colours
- Background: `#000000`
- Text: `#9FE4EF`
- Accent: `#B8F4FC`

The package itself is `Appanoose 2077.nnwtheme`.

## Install on macOS

1. Double-click `Appanoose 2077.nnwtheme`.
2. Confirm the import in NetNewsWire.
3. Open Settings, then Appearance, and set Article Theme to Appanoose 2077.

## Install on iPhone or iPad

1. Copy `Appanoose 2077.nnwtheme` to the Files app.
2. In NetNewsWire, open Settings, then Theme.
3. Tap + and choose `Appanoose 2077.nnwtheme`.

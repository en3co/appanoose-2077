# Appanoose 2077

A NetNewsWire article theme based on the pre-bundled Appanoose theme. Solid black page, ice-cyan text, and a bright cyan header bar. The typeface is Rajdhani, bundled in the theme.

- Background: `#000000`
- Text: `#9FE4EF`
- Accent: `#B8F4FC`
- Site: [enricoarapi.com](https://enricoarapi.com/)

The package is `Appanoose 2077.nnwtheme`.

## Install on macOS

1. Double-click `Appanoose 2077.nnwtheme`.
2. Confirm the import in NetNewsWire.
3. If an older Appanoose 2077 theme is already installed, delete it first, then import this one.

## Install on iPhone or iPad

1. Copy `Appanoose 2077.nnwtheme` to iCloud Drive or On My iPhone/iPad. Zip it first if Files will not keep the package intact, then unzip it on the device.
2. In NetNewsWire, open Settings, then Theme.
3. Tap + and choose `Appanoose 2077.nnwtheme`.
4. Delete any earlier Appanoose 2077 theme before importing this build.
